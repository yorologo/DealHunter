# Market, Turbo & Stores

Las vistas generales (`/market`, `/turbo`, `/stores`) soportan:
- Filtros por categoría y orden.
- Paginación Server-Side (optimizada mediante HTMX y SQL `LIMIT`/`OFFSET`).
- Visualización compacta de disponibilidad, precio unitario (`unit_price`) y acceso rápido a Comparador o Detalle.
