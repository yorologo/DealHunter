# Product Detail

La pantalla central de investigación de producto organiza la información usando la jerarquía:

`DECISIÓN` → `EXPLICACIÓN` → `COMPARACIÓN` → `DATOS TÉCNICOS`

## Tabs
- **Resumen**: Muestra la conclusión (Price Intelligence) y características clave.
- **Histórico**: Renderiza un gráfico temporal generado con **Chart.js (Offline)**. Filtros client-side: 7D, 30D, 90D, Todo.
- **Comparar**: Lista candidatos similares anclados a este producto.
- **Observaciones**: Volcado crudo tabular de los registros recientes de SQLite.
