# Modos: Discover vs Update

- **DISCOVER**: Recomendado ocasionalmente (ej. 1 vez por semana). Explora desde verticales, expandiendo por sugerencias de tiendas y nuevas búsquedas para encontrar productos desconocidos.
- **UPDATE**: Recomendado frecuentemente (ej. varias veces al día). Refresca productos y tiendas ya conocidas leyendo los queries más populares del historial reciente.

```bash
rappi-ofertas discover
rappi-ofertas update
```
