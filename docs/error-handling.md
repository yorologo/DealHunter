# Error Handling and Codes

DealHunter estandariza y captura fallos para evitar caídas catastróficas, propiciando ejecuciones `PARTIAL`.

Códigos estructurados vigentes:
- `NETWORK_ERROR`
- `TIMEOUT`
- `HTTP_429`
- `CLOUDFLARE_LIMIT`
- `INVALID_RESPONSE`
- `PARSER_ERROR`
- `DB_LOCKED`
- `DB_CORRUPT`
- `CONFIG_ERROR`
- `PARTIAL_RUN`
- `REQUEST_BUDGET_REACHED`
